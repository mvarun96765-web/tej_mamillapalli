1. Application Purpose

VARUN TEJ is a professional market-intelligence and AI trading-analysis application.

The application is inspired by the professional experience of applications such as Groww and Angel One,
but it is not intended to be a direct copy of their UI.

The application will primarily provide:

        · Live market prices
        · Stocks
        · Options
        · Market news
        · Historical news analysis
        · AI-based market analysis
        · AI-generated signals
        · Target price
        · Stop-loss
        · Avoid signals
        · Top stock opportunities
        · Top option opportunities
        · Daily market intelligence
The application itself should not execute trades or place buy/sell orders.

It is an analysis and decision-support application.

8. API Key Security Requirements

AI model integration lo key security UI design kanna important. Ee rules mandatory ga follow cheyyali.
1. Never store API key in plain text in local preferences, SharedPreferences, SQLite, or normal JSON config.
2. Use secure platform storage / encrypted secret storage appropriate to the target platform.
3. Never print API keys in console logs, debug logs, crash reports, analytics, or telemetry.
4. Never send API key from the mobile UI directly to third-party systems except the intended provider request path.
5. Prefer backend-mediated provider calls when the architecture requires stronger secret protection.
6. Never place secret keys in source code, Git, screenshots, README files, or public build artifacts.
7. API key field must always be masked by default.
8. When editing an existing model, show only a masked indicator; do not retrieve and display the full secret.
9. Remove flow must delete the encrypted secret and related model configuration.
10. Verification response should store only safe metadata: verified status, provider/model, timestamp, latency, and
sanitized error category.

Safe data model concept

Store: provider, modelName, endpoint, status, verifiedAt, lastErrorCategory, latencyMs, secretReference.
Do not store/display in normal app state: raw API key.
